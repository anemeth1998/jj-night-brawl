# Adding binary assets to this private repo

The Grok GitHub connector uploads **text** files reliably. Large PNGs should be pushed from your Mac:

1. Download `jj-night-brawl-assets-backup.tar.gz` from the Grok project.
2. Unpack it.
3. Copy into a local clone of this repo under `assets/`.
4. `git add` / `commit` / `push`.

Alternatively drag-and-drop folders in the GitHub web UI (private repo → Add file → Upload).
