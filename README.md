# JJ: Night Brawl

32-bit side-scrolling beat-em-up. Playable web build.

## Roster

- **JJ** — punk lead, story mode
- **Andrew** — scene coder (hover: laptop, sitting cross-legged)
- **Han** — cat-ear chaos (hover: on her phone)

Enemies: white-collar suits, MAGA hats, goths.

## Play

```
npm install
npm run dev
```

Title screen → PRESS START → Menu Select (brick-wall loop).  
Story / Endless / Character Select / World Map / Shop / Gallery.
