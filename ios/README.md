# JJ: Night Brawl — iOS / Xcode

## Location

```text
ios/JJNightBrawl/                    ← open this project
ios/JJNightBrawl/JJNightBrawl.xcodeproj
ios/JJNightBrawl-Xcode.tar.gz        ← packed download
```

## Import into Xcode

1. Copy `ios/JJNightBrawl` to your Mac (or unpack `JJNightBrawl-Xcode.tar.gz`).
2. Double-click **`JJNightBrawl.xcodeproj`**.
3. Select an iPhone simulator → **⌘R**.

Full details, controls, and gun notes: see **[JJNightBrawl/README.md](JJNightBrawl/README.md)**.
